- 状态：v3 已完成任务 1–4；v4 已确认（2026-11-23），实施任务 5、6
- 版本：v4（v1 → v2：新增「收起时显示任务标题」开关；v2 → v3：刘海屏离顶距离从刘海顶部算起，重叠时内容躲开刘海；v3 → v4：椭圆胶囊收起时可设中间留空）

## 目标与范围

给 macOS 任务胶囊（代码里叫 `agentIsland`，界面上叫「任务胶囊」）增加两项外观设置：

1. **椭圆胶囊样式**：一个悬浮的黑色椭圆胶囊，四角都是圆角，和屏幕顶边之间留有空隙，参考用户提供的两张截图。
2. **收起时显示任务标题**：开关。关掉后，收起的胶囊只显示角色和计数徽标，并自动变窄。

要做的：

- 设置页「灵动岛」分区新增「胶囊样式」：刘海样式（现状）/ 椭圆胶囊。
- 选椭圆胶囊后，出现两个滑杆：胶囊高度、离顶距离。
- 椭圆样式下，收起态是两端半圆的胶囊，点开后是四角大圆角（约 28pt）的悬浮矩形；收起和展开之间平滑过渡。
- 新增「收起时显示任务标题」开关，两种样式都生效，设置页中始终显示。

不做的：

- 除「收起时显示任务标题」开关外，不改胶囊里显示的内容（角色、计数、余量、展开后的任务行和按钮等），也不改它什么时候出现、什么时候展开。
- 不改苹果系统灵动岛上的实时活动（`live-activity/`）。
- 不加上下拖动胶囊的手势；高度和离顶距离只在设置页里调。
- 不改 Windows（Windows 本来就没有任务胶囊）。

## 已确认的需求与决策

| 问题 | 用户选择 |
| --- | --- |
| 改什么 | 内容和出现时机不变，做椭圆胶囊外观 |
| 刘海屏怎么处理 | 加设置项，让用户在刘海样式和椭圆之间选 |
| 默认样式 | 默认刘海样式。用户升级后看到的和现在完全一样，自己切换后才变成椭圆 |
| 位置和高度 | 由用户调整，方式是设置页里的滑杆 |
| 展开态形状 | 大圆角矩形（约 28pt），和收起态一样悬浮 |
| 标题开关的生效范围 | 刘海样式和椭圆胶囊都生效 |
| 关掉标题时的进度说明 | 一起隐藏，收起时只剩角色和计数徽标 |
| 关掉标题时的宽度 | 自动变窄到刚好放下角色和计数徽标；用户保存的宽度不改，重新打开标题就恢复 |
| 收起时中间留空（v4） | 用户看过实屏效果后提出：收起时在各种宽度下都把中间留空，方便对照刘海 / 挖孔摆放 |
| 留空宽度怎么定（v4） | 设置里加滑杆「中间留空宽度」 |
| 留空生效范围（v4） | 只对椭圆胶囊；刘海样式保持现状 |
| 留空默认值（v4） | 默认 0，即不留空，和现在一样 |
| 滑杆布局（v4） | 三个滑杆（高度、离顶、留空）放在同一行 |
| 滑杆范围（v4） | 放大：高度 18–60pt、离顶 0–32pt、留空 0–400pt；默认值不变（32 / 6 / 0）。替代 v3 的 20–40 / 0–12 |

由此定下、请一并确认的细节（属于本计划的提议）：

- 滑杆范围：高度 20–40pt，默认 32pt（与参考图一致）；离顶距离 0–12pt，默认 6pt。两个滑杆只在选中椭圆时出现。
- 离顶距离一律从屏幕顶边算起（刘海屏即从刘海顶部算起，用户 v3 确认）。刘海屏上椭圆胶囊居中时会和刘海重叠，
  此时保留现有「刘海两侧分栏」内容排布：角色和标题在刘海左侧、计数徽标在右侧，只把外形换成椭圆（用户 v3 确认）。
- 展开态的顶部间距跟收起态保持一致，面板整体悬浮，不再贴顶。
- 「收起时显示任务标题」默认打开，升级后与现在一致。
- 设置保存在本机（与角色皮肤等现有设置相同），不跨设备同步。
- 收起态内容：无刘海屏和挖孔屏沿用现有「无刘海屏」排布（`CompactSessionView.regularBody` / `CompactReminderView` / `IdleIslandView`），
  刘海屏沿用现有刘海分栏排布：
  - 有任务（标题开关打开）：左端是角色（运行中有动画）+ 任务标题（运行中有流光文字），宽度够时标题后跟当前进度说明；右端是计数徽标（「待关注 · 运行中」，运行中橙、等你处理青、未读完成绿）。变窄时先隐藏进度说明，再隐藏计数徽标。
  - 有任务（标题开关关闭）：左端只有角色，右端只有计数徽标，胶囊自动变窄。刘海样式下同理：刘海左侧只有角色，右侧只有计数徽标。
  - 新提醒：左端角色或出错图标，右端计数徽标（本来就没有标题，不受开关影响）。
  - 空闲：角色和余量芯片居中，左右两端不分栏（没有任务标题，不受开关影响）。
  - 展开态不受标题开关影响。
  - 椭圆样式两端变成半圆后，左右内边距随胶囊高度加大（约为高度的一半），避免角色和计数徽标被圆弧切掉。

### v4 新增：中间留空

由此定下、请一并确认的细节：

- 留空滑杆 0–400pt，步长 1pt，默认 0；只在选中椭圆胶囊时出现，与高度、离顶滑杆同一行。
- 留空大于 0 时，椭圆收起态的内容分到两端，中间空着，沿用现有刘海分栏的排布（已在刘海屏上使用）：
  - 有任务：左端角色 + 任务标题（放得下时），右端进度说明 + 计数徽标；关掉标题时左端只有角色、右端只有计数徽标。
  - 新提醒：左端角色或出错图标，右端计数徽标。
  - 空闲：左端角色，右端余量芯片。
- 收起宽度至少要放得下「留空 + 两端内容」；用户保存的宽度比这个窄时，按最小宽度显示，不改写保存的宽度。
  关掉标题时的自动宽度同样是「留空 + 角色 + 计数徽标」。
- 刘海屏上选椭圆时，留空取「滑杆值」和「刘海宽度」中较大的一个，内容始终躲开刘海；藏进刘海的行为不变。
- 展开态不受影响。
- 说明（不改）：新款挖孔屏上现有逻辑不做居中吸附（系统灵动岛叠在上面且不吞点击），对准挖孔需要用户手动拖动。

## 现有能力与复用方案（已核实）

- **形状**：`native/agent-island/macos-agent-island-helper.swift` 里的 `NotchShape` 负责画刘海轮廓（平直顶边 + 反向圆角「肩」+ 底部圆角），
  `AgentIslandRootView.islandBody` 用它填充黑底并裁剪内容。椭圆样式新增一个可动画的圆角形状（收起时圆角 = 高度一半，展开时约 28pt），
  按样式在两种形状之间切换；`NotchShape` 原样保留。
- **尺寸**：`AgentIslandLayout.compute` 目前把收起高度设为菜单栏高度（`notchBaselineHeight`，无刘海屏约 24pt），
  展开高度按内容计算。椭圆样式下，收起高度改用滑杆值，并加上离顶距离；展开高度的计算不变。
- **刘海分栏**：椭圆样式不关闭刘海分栏（`hardwareNotchLayoutEnabled` 保持现有判定），刘海屏的内容排布、宽度吸附逻辑原样复用，只换外形和高度。
- **收起标题**：标题和进度说明分别在 `CompactSessionView` 的 `compactTitleLine`（无刘海排布）和
  `hardwareNotchLeadingContent` / `hardwareNotchTrailingContent`（刘海排布）里绘制，按开关跳过即可。
- **自动变窄**：`AgentIslandLayout.compute` 里新提醒状态已经有「只放角色 + 计数徽标」的最小宽度算法
  （无刘海：图标宽度 + 内边距 + `PillBadge.intrinsicWidth`；刘海：`defaultCompactWidth` 含徽标宽度），关掉标题时复用同一算法作为收起宽度，
  不改写用户保存的宽度（与提醒状态「不改写保存宽度」的做法一致）。
- **设置传递链路**：照搬「角色皮肤」的做法：设置页存 localStorage（`useAgentIslandSettings.ts`）→ preload 的 `agentIsland.*` →
  main `AgentIslandService` 的 IPC handler → 显示状态 JSON 下发给 helper（`displayMascotSkin` 那一路）。新设置作为一个对象
  （样式 + 高度 + 离顶距离 + 是否显示收起标题）走同一条链路，需新增一个 IPC channel。
- **设置页控件**：用现有标准组件 `SegmentedControl`（样式二选一）、`Slider`（两个滑杆）和现有开关控件，放进 `AgentIslandSection.tsx`。
- **文案**：新增文案走 i18n，覆盖全部语言文件，术语按 `i18n/glossary.json`（「任务胶囊」「灵动岛」的既有叫法）。

待实现时验证的假设：

- 离顶距离打算在胶囊窗口内部做偏移，而不是移动窗口本身。这样还需要同步偏移鼠标悬停和点击的判定区域
  （`TrackingLayer`、`PanelPointerHit` 里按 `menuBarZoneHeight` 分区的逻辑）。如果窗口高度不够放下偏移量，改为调整窗口位置，并在计划里记录。
- 刘海屏「藏进刘海」宽度（胶囊宽度不超过刘海）时，如果椭圆高度加离顶距离超过刘海高度，胶囊下沿会从刘海底下露出来。
  计划在这种状态下不绘制椭圆底色，保持完全藏进刘海；实现时核对效果。
- 自动变窄时，拖左右边改宽度的手势在「标题隐藏」状态下如何表现：计划保持现有提醒状态的行为（显示宽度按最小宽度，拖动仍写入用户宽度偏好）。实现时核对，如有不一致在计划里记录并告知。

## 影响与风险

- 涉及模块：Desktop 的 `shared/agentIsland.ts`、`main/agent-island/service.ts`、`preload`、`renderer` 设置页与 hook、原生 helper（Swift）、i18n 语言文件。
- 兼容：默认刘海样式、显示标题，老用户升级后外观不变；新字段可选，helper 收到旧格式状态时按默认处理。
- 新增 IPC channel 只在本机设置页与 main 之间使用，不经过跨设备协议；会按规则核对是否需要登记到 IPC 白名单或远程适配清单。
- 风险最大的是原生 helper：它是 7500 多行的单文件，悬停 / 点击区域、拖动吸附和窗口高度都依赖现有的「贴顶」假设，偏移后容易出现点不到、悬停误判。
  做法是只在椭圆样式分支里改，刘海样式的代码路径不动。
- 标题开关会影响刘海样式的收起宽度计算，刘海屏的「藏进刘海 / 基本宽度」吸附逻辑较复杂（`snappedCompactHardwareWidth`），只在开关关闭时走新分支，打开时原逻辑不变。
- 回退：设置切回刘海样式、打开标题即可恢复原外观；代码层面每步一个提交，可单独回退。
